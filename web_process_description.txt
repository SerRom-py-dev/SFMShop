Процесс загрузки сайта при вводе URL в браузере:

1. DNS-запрос (~10-50 мс)
   - Браузер преобразует доменное имя (sfmshop.com) в IP-адрес (192.168.1.1)
   - Проверяется кэш DNS
   - Если адреса нет в кэше, отправляется запрос DNS-серверу
   - Возможные проблемы: медленный DNS-сервер, проблемы с сетью

2. Установка TCP-соединения (~50-200 мс)
   - Браузер устанавливает соединение с сервером по IP-адресу
   - Отправляется запрос на установку соединения
   - Сервер подтверждает соединение
   - Возможные проблемы: сервер недоступен, проблемы с сетью

3. HTTP-запрос (~10-50 мс)
   - Браузер отправляет HTTP-запрос серверу
   - Запрос содержит метод (GET), путь (/products), заголовки
   - Возможные проблемы: неправильный формат запроса

4. Обработка на сервере (~100-500 мс)
   - Сервер получает запрос
   - Определяет обработчик (endpoint)
   - Выполняет код (например, получает данные из БД)
   - Формирует ответ
   - Возможные проблемы: медленные запросы к БД, медленный код

5. HTTP-ответ (~10-50 мс)
   - Сервер отправляет HTTP-ответ браузеру
   - Ответ содержит статус (200 OK), заголовки, данные
   - Возможные проблемы: большой размер ответа, проблемы с сетью

6. Рендеринг в браузере (~50-200 мс)
   - Браузер получает ответ
   - Парсит данные (JSON, HTML)
   - Отображает данные на странице
   - Возможные проблемы: медленный парсинг, сложная отрисовка

Общее время: ~230-1050 мс (0.2-1 секунда)
