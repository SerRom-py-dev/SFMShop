# Git Workflow для проекта SFMShop

## Использованные команды Git

### Базовые команды
- `git init` - инициализация репозитория в папке SFMShop
- `git add .` - добавление всех файлов в staging area
- `git commit -m "сообщение"` - создание коммита с сообщением
- `git status` - просмотр текущего состояния репозитория
- `git log --oneline` - просмотр истории коммитов в компактном виде

### Работа с ветками
- `git branch` - просмотр списка веток
- `git branch feature/name` - создание новой ветки
- `git checkout branch_name` - переключение на ветку
- `git checkout -b feature/name` - создание и переключение на ветку

### Работа с удаленным репозиторием
- `git remote add origin URL` - добавление удаленного репозитория
- `git push -u origin branch_name` - отправка ветки в удаленный репозиторий
- `git pull origin main` - получение изменений из удаленного репозитория

### Анализ изменений
- `git diff` - просмотр изменений в рабочей директории
- `git diff branch1 branch2` - сравнение двух веток
- `git show commit_hash` - просмотр конкретного коммита
- `git log --stat` - просмотр статистики изменений

## Созданные ветки

- `main` - основная ветка проекта, содержит стабильный код
- `feature/add-discount-system` - ветка для разработки системы скидок
- `feature/add-logging` - ветка для добавления системы логирования
- `feature/add-caching` - ветка для добавления системы кэширования

## Разрешенные конфликты

При слиянии ветки `feature/add-discount-system` в `main` возник конфликт в файле `src/models/product.py`. Конфликт был разрешен объединением обеих версий метода `get_total_price()`.

## Стратегия работы с ветками

1. **Основная ветка (main)**: содержит только проверенный и протестированный код
2. **Feature-ветки**: создаются для каждой новой функции, называются `feature/название-функции`
3. **Workflow**: создание ветки > разработка > коммиты > PR > код-ревью > слияние в main
4. **Обновление веток**: регулярно обновлять feature-ветки из main для предотвращения конфликтов
5. **Короткие ветки**: feature-ветки живут недолго, после слияния удаляются
