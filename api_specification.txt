API Спецификация для проекта SFMShop

=== ТОВАРЫ ===

1. GET /products
   Описание: Получение списка всех товаров
   Параметры запроса:
     - limit (query, optional): количество товаров (по умолчанию 10)
     - offset (query, optional): смещение (по умолчанию 0)
   Статусы:
     - 200 OK - успешно
     - 500 Internal Server Error - ошибка сервера
   Пример запроса:
   GET /products?limit=10&offset=0 HTTP/1.1
   Host: sfmshop.com
   
   Пример ответа (200 OK):
   HTTP/1.1 200 OK
   Content-Type: application/json
   [
     {"id": 1, "name": "Ноутбук", "price": 50000, "quantity": 10},
     {"id": 2, "name": "Мышь", "price": 1500, "quantity": 20}
   ]

2. GET /products/{id}
   Описание: Получение товара по ID
   Параметры пути:
     - id (path, required): ID товара
   Статусы:
     - 200 OK - успешно
     - 404 Not Found - товар не найден
     - 500 Internal Server Error - ошибка сервера
   Пример запроса:
   GET /products/1 HTTP/1.1
   Host: sfmshop.com
   
   Пример ответа (200 OK):
   HTTP/1.1 200 OK
   Content-Type: application/json
   {"id": 1, "name": "Ноутбук", "price": 50000, "quantity": 10}
   
   Пример ответа (404 Not Found):
   HTTP/1.1 404 Not Found
   Content-Type: application/json
   {"error": "Товар с id=1 не найден"}

3. POST /products
   Описание: Создание нового товара
   Тело запроса (JSON):
     - name (string, required): название товара
     - price (number, required): цена товара
     - quantity (integer, optional): количество на складе
   Статусы:
     - 201 Created - товар создан
     - 400 Bad Request - неправильные данные
     - 500 Internal Server Error - ошибка сервера
   Пример запроса:
   POST /products HTTP/1.1
   Host: sfmshop.com
   Content-Type: application/json
   {"name": "Клавиатура", "price": 3000, "quantity": 15}
   
   Пример ответа (201 Created):
   HTTP/1.1 201 Created
   Content-Type: application/json
   {"id": 3, "name": "Клавиатура", "price": 3000, "quantity": 15}

4. PUT /products/{id}
   Описание: Обновление товара
   Параметры пути:
     - id (path, required): ID товара
   Тело запроса (JSON):
     - name (string, optional): название товара
     - price (number, optional): цена товара
     - quantity (integer, optional): количество на складе
   Статусы:
     - 200 OK - товар обновлен
     - 404 Not Found - товар не найден
     - 400 Bad Request - неправильные данные
     - 500 Internal Server Error - ошибка сервера
   Пример запроса:
   PUT /products/1 HTTP/1.1
   Host: sfmshop.com
   Content-Type: application/json
   {"price": 45000}
   
   Пример ответа (200 OK):
   HTTP/1.1 200 OK
   Content-Type: application/json
   {"id": 1, "name": "Ноутбук", "price": 45000, "quantity": 10}

5. DELETE /products/{id}
   Описание: Удаление товара
   Параметры пути:
     - id (path, required): ID товара
   Статусы:
     - 200 OK - товар удален
     - 404 Not Found - товар не найден
     - 500 Internal Server Error - ошибка сервера
   Пример запроса:
   DELETE /products/1 HTTP/1.1
   Host: sfmshop.com
   
   Пример ответа (200 OK):
   HTTP/1.1 200 OK
   Content-Type: application/json
   {"message": "Товар удален"}

=== ЗАКАЗЫ ===

6. GET /orders
   Описание: Получение списка всех заказов
   Статусы:
     - 200 OK - успешно
     - 500 Internal Server Error - ошибка сервера
   Пример ответа (200 OK):
   HTTP/1.1 200 OK
   Content-Type: application/json
   [{"id": 1, "user_id": 1, "total": 50000, "created_at": "2024-01-15"}, ...]

7. POST /orders
   Описание: Создание нового заказа
   Тело запроса (JSON):
     - user_id (integer, required): ID пользователя
     - product_id (integer, required): ID товара
     - quantity (integer, required): количество
   Статусы:
     - 201 Created - заказ создан
     - 400 Bad Request - неправильные данные
     - 500 Internal Server Error - ошибка сервера
   Пример запроса:
   POST /orders HTTP/1.1
   Host: sfmshop.com
   Content-Type: application/json
   {"user_id": 1, "product_id": 2, "quantity": 1}
   
   Пример ответа (201 Created):
   HTTP/1.1 201 Created
   Content-Type: application/json
   {"id": 5, "user_id": 1, "product_id": 2, "quantity": 1, "total": 1500}

8. GET /users/{id}/orders
   Описание: Получение заказов пользователя
   Параметры пути:
     - id (path, required): ID пользователя
   Статусы:
     - 200 OK - успешно
     - 404 Not Found - пользователь не найден
     - 500 Internal Server Error - ошибка сервера
   Пример запроса:
   GET /users/1/orders HTTP/1.1
   Host: sfmshop.com
   
   Пример ответа (200 OK):
   HTTP/1.1 200 OK
   Content-Type: application/json
   [{"id": 1, "total": 50000, "created_at": "2024-01-15"}, ...]
